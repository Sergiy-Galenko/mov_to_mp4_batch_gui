# Media Converter

**Перетворіть MOV на MP4, підготуйте фото, витягніть аудіо або зберіть відео з кількох фрагментів в одному застосунку.** Додавайте файли перетягуванням, обирайте формат і папку результатів, а виконання відстежуйте в черзі.

Проєкт починався як пакетний MOV → MP4 конвертер, тому репозиторій досі має назву `mov_to_mp4_batch_gui`. Зараз він також містить редактор монтажу, інструменти субтитрів, конвертацію документів, завантаження за посиланнями.

## Встановлення та запуск

Потрібен **Python 3.12 або новіший**. Інтерфейс адаптовано для macOS і Windows; базові автоматичні перевірки також налаштовані для Linux. Графічні й мультимедійні можливості залежать від системи та встановлених кодеків.

### 1. Отримайте проєкт

Завантажте ZIP через **Code → Download ZIP** на GitHub і розпакуйте його або виконайте:

```bash
git clone https://github.com/Sergiy-Galenko/mov_to_mp4_batch_gui.git
cd mov_to_mp4_batch_gui
```

### 2. Створіть середовище й установіть залежності

**macOS / Linux** — у терміналі в папці проєкту:

```bash
python3 --version
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

Перед створенням середовища переконайтеся, що `python3 --version` показує **3.12+**.

**Windows** — у PowerShell у папці проєкту:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Якщо встановлено новішу версію Python, замініть `-3.12` на її номер. Використання повного шляху до Python із `.venv` не потребує активації PowerShell-скриптом.

### 3. Налаштуйте FFmpeg для роботи з медіа

**FFmpeg** виконує конвертацію медіа, а **FFprobe** читає їхні характеристики. Отримайте збірку для своєї ОС зі [сторінки FFmpeg](https://ffmpeg.org/download.html), розпакуйте та вкажіть шлях до виконуваного `ffmpeg` / `ffmpeg.exe` в налаштуваннях застосунку. Тримайте `ffprobe` / `ffprobe.exe` поруч.

Перевірте обидва виконувані файли з аргументом `-version`. Якщо вони доступні у вашому терміналі:

```bash
ffmpeg -version
ffprobe -version
```

**Застосунок за замовчуванням не шукає FFmpeg у системному PATH.** Вкажіть шлях явно або дозвольте пошук змінною `MEDIA_CONVERTER_ALLOW_PATH_BINARIES=1`. Докладні приклади — у [посібнику](docs/guide.md#ffmpeg).

> Для звичайної конвертації текстових документів FFmpeg не потрібен. Whisper, Rust та хмарні інструменти додаються лише для відповідних сценаріїв. [Таблиця залежностей](docs/guide.md#dependencies).

## Перша конвертація: MOV → MP4

1. **Оберіть папку результатів.** Сюди застосунок записуватиме готові файли.
2. **Додайте MOV.** Перетягніть один або кілька файлів у чергу або натисніть **Додати файли**.
3. **Виберіть MP4.** Для одного файлу відкрийте контекстне меню швидкої конвертації; для черги задайте спільні параметри.
4. **Оберіть профіль.** `Balanced` — базовий баланс розміру та якості. Перевірте, чи потрібні обрізання або зміна роздільності.
5. **Запустіть конвертацію.** Скористайтеся дією для одного файлу або всієї черги та дочекайтеся завершення.
6. **Перевірте результат.** Відкрийте файл із вибраної папки; за помилки перегляньте журнал.

**Зміна контейнера чи перекодування?** Fast Copy / remux копіює сумісні потоки без повторного кодування. Зміна розміру кадру, фільтри та вбудовані субтитри потребують перекодування.

## Формати й обмеження

| Тип | Приклади форматів | Що врахувати |
| --- | --- | --- |
| Відео | MP4, MOV, MKV, WEBM, AVI, GIF | Контейнер і кодек мають бути сумісними; доступні кодери визначає FFmpeg. |
| Зображення | JPG, PNG, WEBP, BMP, TIFF | Прозорість і втрати якості залежать від вихідного формату. |
| Аудіо | MP3, M4A, AAC, WAV, FLAC, OPUS | Перехід між форматами зі втратами може знижувати якість. |
| Субтитри | SRT, ASS, VTT | Стилі не завжди переносяться між форматами. |
| Документи | TXT, MD, HTML, PDF, DOCX, XLSX, PPTX, ODT, ODS, ODP | Складна верстка, формули, макроси й оформлення не гарантуються; старі DOC/XLS/PPT мають спрощені шляхи обробки. |
| Електронні книги | EPUB, FB2, MOBI | Підтримка залежить від структури книги; [деталі](docs/guide.md#documents). |

## Запуск із командного рядка

CLI виконує завдання без відкриття головного вікна. Команди запускайте з підготовленого Python-середовища; для медіа також налаштуйте FFmpeg.

```bash
# Один файл із профілем Balanced
python main.py --cli -i input.mov -o ./converted --profile Balanced

# Кілька файлів; при збігу назв додавати індекс
python main.py --cli -i first.mov second.mov -o ./converted --collision-policy index

# Переглянути всі параметри
python main.py --cli --help
```

Для явного вибору інструментів додайте `--ffmpeg "/шлях/до/ffmpeg" --ffprobe "/шлях/до/ffprobe"`. [Розширені приклади CLI](docs/advanced-guide.md#cli-mode) містять цільовий розмір, JSON-налаштування та завантаження за URL.

## Якщо щось не працює

| Симптом | Що зробити |
| --- | --- |
| `No module named PySide6` | Установіть `requirements.txt` тим самим Python, яким запускаєте `main.py`. |
| FFmpeg не знайдено, хоча він є в терміналі | Укажіть повний шлях у застосунку або дозвольте пошук у PATH. |
| Не запускається конвертація | Оберіть папку результатів, перевірте доступ до файлів, вільне місце й повідомлення перевірки перед запуском. |
| Whisper не розпізнає мовлення | У менеджері моделей установіть рушій, завантажте модель, перевірте пристрій та виконайте тест. |
| `QQmlApplicationEngine failed to load component` | Подивіться останній рядок ланцюжка помилок: він указує файл і місце першопричини. [Діагностика QML](docs/development.md#qml). |

Для звернення про помилку додайте ОС, версію Python, кроки відтворення та текст журналу в [GitHub Issues](https://github.com/Sergiy-Galenko/mov_to_mp4_batch_gui/issues). Не додавайте ключі ліцензій, cookies або приватні медіафайли.
