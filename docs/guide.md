# Посібник користувача

## Перша конвертація

1. Додайте файли перетягуванням або через «Додати файли».
2. Виберіть папку результатів і формат.
3. Виберіть пресет, перевірте налаштування та запустіть чергу.
4. За помилки перегляньте журнал і повідомлення перевірки перед запуском.

## Пресети

Вибір розділено на **Вбудовані** та **Користувацькі**. Вбудовані пресети захищені від перезапису. Щоб створити власний, введіть нову назву й натисніть **Зберегти як**. Для редагування завантажте користувацький пресет, змініть параметри й натисніть **Зберегти**.

Експорт JSON містить користувацькі пресети. Імпорт перевіряє налаштування. За конфлікту назв можна замінити користувацькі пресети, залишити наявні або скасувати імпорт. Вбудовані пресети при заміні імпортуються як окремі копії.

Пресети зберігаються у `presets.json` у каталозі даних застосунку: `~/Library/Application Support/MediaConverter` на macOS, `%USERPROFILE%/AppData/Local/MediaConverter` на Windows, `~/.local/share/MediaConverter` на Linux. Portable-режим використовує каталог `data` поруч із програмою.

## Target size

**MB = 1 000 000 байтів**. Ліміт задається для кожного відео. Порожнє поле вимикає режим. Застосунок віднімає бюджет аудіо й резервує 6% для контейнера, виконує два проходи H.264 на CPU та перевіряє фактичний розмір до публікації результату. При перевищенні знижує бітрейт і повторює кодування до двох разів. Якщо ліміт недосяжний, повідомляє про помилку; завеликий файл не публікується.

Підтримуються MP4, MOV, MKV та AVI. Виберіть H.264 або Auto. ProRes, інші явно вибрані кодеки й об’єднання файлів несумісні з цим режимом. Для ProRes вимкніть Target size та виберіть MOV або MKV.

Після визначення тривалості показуються відео-бітрейт, аудіо-бітрейт і мінімальний бюджет. При малому бітрейті можна застосувати запропоновану меншу роздільність. Це допомагає якості; бюджет аудіо зменшується окремо.

## FFmpeg

FFmpeg кодує медіа, FFprobe читає тривалість і характеристики. Укажіть шлях до FFmpeg в налаштуваннях; FFprobe має бути поруч. Перевірте обидва виконувані файли аргументом `-version`.

Пошук у PATH можна дозволити через `MEDIA_CONVERTER_ALLOW_PATH_BINARIES=1`. Явні шляхи також задаються змінними `MEDIA_CONVERTER_FFMPEG` та `MEDIA_CONVERTER_FFPROBE`.

## Dependencies

- Python 3.12+ та пакети з `requirements.txt`: основний застосунок.
- FFmpeg / FFprobe: відео, аудіо, аналіз медіа.
- Whisper: додаткове розпізнавання мовлення; налаштовується в менеджері моделей.
- 7-Zip / WinRAR: відповідні архівні операції.
- Rust: необов’язкове прискорення; Python-реалізація залишається доступною.
