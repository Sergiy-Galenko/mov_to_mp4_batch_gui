# Зображення документації

| Файл | Джерело та зміст |
| --- | --- |
| `readme-banner.svg` | Векторне оформлення документації; приклад MOV → MP4. |
| `queue-dark.png` | Справжній QML-інтерфейс черги, темна тема, 1240 × 840. |
| `queue-light.png` | Та сама демонстраційна черга, світла тема, 1240 × 840. |

Знімки редактора створено в ізольованому QML-середовищі з поточної робочої копії. Вони показують порожній стан і стан із вибраним кліпом; приватні файли не використовуються.

Демонстраційна обкладинка — копія власного логотипа з `assets/app-logo-v2.png`. Текстовий файл і субтитри створюються скриптом; приватних матеріалів немає. У зображеннях немає накладених або згенерованих елементів інтерфейсу. Видима папка джерел — тимчасовий каталог.

Зображення та документація поширюються на умовах кореневого [LICENSE](../../LICENSE). Інформація про походження логотипа — у [branding.md](../branding.md).
